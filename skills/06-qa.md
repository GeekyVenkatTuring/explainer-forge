# Skill 06 — QA: The Still-Review Protocol (mandatory)

This step is where the gold videos got their quality. Code review cannot catch visual
bugs; **you must render frames and LOOK at them** before the final render. Budget
~10 minutes; it has caught real, embarrassing bugs every single time.

## Protocol

1. **Build test props** covering EVERY variant (no TTS needed — fake durations):
   give each scene 30s and compute mid-scene frames. Generate `/tmp/<set>_test_props.json`
   with a small Python snippet: cuts of 30s each, `props: {dur: 30, ...demo props}`.

2. **Render one mid-animation still per scene** (~60% through, when most phases have
   landed but continuous motion is visible). From `composer/`:
   ```bash
   # scene i of 30s cuts → frame = i*900 + 540
   npx remotion still Explainer /tmp/stills/s$i.png --props=/tmp/test_props.json --frame=$((i*900+540))
   ```
   Frame index must fall INSIDE the intended cut — miscounting reviews the wrong
   scene (it has happened; double-check `i*900+540` against the cut you meant).

3. **Read every still as an image** and check the list below. Don't skim — look at
   each element and ask "is this what the narration claims?"

4. **Fix → re-render only the affected stills → verify.** Then final render.

4b. **Duration / frozen-frame check (a mid-still can't show it).** Print every segment's
   `dur` (build.py has it, and warns `⚠ LONG >90s`). For any scene > ~75s, render a still
   at p≈0.95 and confirm the content is developed (not mid-freeze) with a visible
   motion/progress signal. Long single-visual beats get split (skills/02, 09) or lean on
   the scene-progress bar (skills/03). Shipped defect: a 96s title static ~46s under audio.

4c. **A/V-sync check (mandatory for any beat with staggered reveals).** The build emits
   `captions` cues that are audio-timed. For a scene, list the cue timestamps (when each
   item is *spoken*), then render a still at that timestamp and confirm the corresponding
   element is ON SCREEN, not still to come. If items appear seconds AFTER they're named,
   the reveals lag the audio (a shipped defect: up to 30s late) — pull the reveals earlier
   to match the spoken order (skills/02 §"A/V-lag defect"). Front-loaded narration ⇒
   front-loaded reveals.

5. **After the final render**: extract 2–3 frames from the actual MP4 (ffmpeg -ss)
   and check them — confirms A/V mux and that props/audio didn't drift.

## What to look for (catalog of real bugs caught)

| Class | Real examples caught at QA |
|---|---|
| Text collisions | title subtitle overlapped a decorative grid; VRAM tower labels crushed while segments grew |
| Garbled data text | counter suffix rendered "1000$" instead of "1000s"; "1 → months" nonsense — replaced counters with plain labels |
| Metaphor direction | balance scale: the "winning" side went UP (heavier must sink); beam rotation sign disagreed with pan offsets |
| Occlusion/stacking | RGB channel grids stacked with too-small offsets — only the top one visible |
| Moving-element collisions | a driving car's tracked box crossed the dog/person boxes — re-laned all actors |
| Phase timing | a scene whose last reveal fired at p=0.3 (frozen back half) — spread phases to 0.85 |
| Legibility | muted text < 20px; dark-on-dark chip text |
| Off-stage drift | x+w > 1820, elements clipped at frame edge |

## Checklist per still
- [ ] Everything inside 1820×1000 safe area; nothing clipped
- [ ] No unintended overlaps at THIS moment (imagine ±20% of the beat too) — and
      re-run skill 09 §9's overlap checklist against what you SEE, not what you wrote
- [ ] Frame anatomy per skill 09: header/content/footer zones respected; one hero
      element; typography sizes from the hierarchy table (nothing below 19px)
- [ ] Every metaphor's direction/sign is correct
- [ ] Numbers/labels legible and sensible ("15 trillion+", not "15T+$")
- [ ] Continuous motion visible (particles/beam/glow present mid-scene)
- [ ] The visual matches what the narration says at ~this point of the beat
- [ ] Colors follow the identity's semantic assignments

Never ship a scene you haven't seen rendered.
